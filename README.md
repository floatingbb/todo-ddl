# ToDo deadline list · 本地分享版

一个使用柔和配色的课程待办工作台。HTML、CSS 和 JavaScript 都包含在 `ToDo.html` 中，下载后可直接在浏览器打开，不需要安装依赖、构建项目、注册账号或配置服务器。

> **本项目是单文件本地版，不是 ChatGPT 托管版。没有账号登录、云端数据库或多设备自动同步。电脑、手机、不同浏览器之间的数据各自独立；即使使用相同的 GitHub 或浏览器账号，也不会由本程序自动同步。**

## 开始使用

1. 在仓库页面选择 **Code → Download ZIP**，下载并解压。
2. 使用现代浏览器打开解压后的 `ToDo.html`。直接查看 GitHub 上的源代码页面不会运行程序。
3. 在“管理课程”中修改两个通用示例课程，或添加自己的课程。
4. 点击“添加任务”，填写任务名称、所属课程、重要性、截止日期时间及说明。
5. 在“工作台设置”中调整名称、说明和主题颜色。

首次打开只显示通用示例课程，没有预置任务。文件下载后可离线使用，不依赖第三方脚本、字体服务或接口。浏览器需要支持 JavaScript、`localStorage` 及页面使用的现代 CSS 特性。

## 功能说明

| 功能 | 具体行为 |
| --- | --- |
| 课程分类 | 添加课程，修改名称和颜色，上下调整课程顺序；侧栏显示课程列表，可以切换课程视图。 |
| 删除课程 | 课程下存在任务时会阻止删除，需先修改这些任务的所属课程或删除任务；删除课程前会确认。 |
| 新建和编辑任务 | 支持任务名称、所属课程、任务说明、高/中/低重要性及可选的截止日期和时间。 |
| 截止时间 | 新任务的时间输入默认是 23:59；可以修改，也可以不设置截止日期。 |
| 任务状态 | 未开始、进行中、已完成；通过下拉框或完成复选框更新，记录完成时间，支持将已完成任务改回未完成状态。 |
| 删除任务 | 删除前弹窗确认；删除操作没有内置回收站或撤销功能。 |
| 组合筛选 | 按课程及任务状态组合筛选，并可一键重置筛选。 |
| 任务排序 | 未完成任务按截止时间从早到晚排列，无截止日期的未完成任务靠后；已完成任务位于未完成任务之后，按完成时间由近到远排列。重要性以标签展示，不决定任务排序。 |
| 总体统计 | 展示全部课程的总任务量、已完成量、进行中数量和整体完成百分比及进度条。 |
| 各课程进度 | 按课程统计已完成任务比例，任务状态变化后更新进度。 |
| DDL 列表 | 按截止时间展示有截止日期且未完成的任务，显示剩余时间或逾期时长；已完成任务自动退出时间线。 |
| 可视化时间轴 | 区分逾期任务与未来任务，未来任务按时间比例分布，配有任务标记和标签。 |
| 时间自动刷新 | 页面打开期间，每分钟刷新任务与时间线中的剩余时间和逾期时间；依赖设备当前时间与时区。 |
| 完成反馈 | 新完成任务时显示庆祝动画。 |
| 工作台自定义 | 修改标题、说明、主题主色、辅助色及背景色；颜色输入提供预览。保存设置后写入本机存储。 |
| 响应式排版 | 原文件包含 1100px、760px、480px 等断点，窄屏调整侧栏、卡片、表单和布局。手机能否直接打开本地 HTML 取决于系统、浏览器和打开方式。 |
| 弹窗操作 | 支持关闭按钮、点击遮罩和 Esc 关闭弹窗。 |
| 本机保存 | 课程、任务、设置写入当前浏览器的 `localStorage`，在浏览器保留且允许该存储的情况下重新打开可继续使用。 |

## 数据保存与限制

### 不支持多设备同步

此文件没有服务器、登录系统、云数据库或同步接口。它不会将任务发送到 GitHub，也不会因为文件存放在 GitHub、网盘，或用户登录了同一个浏览器账号而自动合并任务。

复制 `ToDo.html` 只会复制程序，不会复制已经填写的任务：这些数据在浏览器存储里，不会写回 HTML 文件。本版本也没有内置数据导入、导出、备份和恢复按钮。不要将它当作唯一的数据备份。

### 浏览器存储不等于文件存储

- 不同设备、浏览器、浏览器用户配置的数据通常彼此独立。
- 直接通过 `file://` 打开时，`localStorage` 行为取决于浏览器。重命名、移动文件或更换打开方式后，可能访问不到原数据；不能依赖不同文件路径间共享数据。
- 清理浏览器站点数据、删除用户配置、隐私模式退出或浏览器存储受限，都可能导致数据丢失或无法保存。
- 页面没有跨标签页数据合并机制；同一存储位置同时打开多个页面编辑，可能互相覆盖。建议只在一个页面编辑。
- 页面关闭后不会在后台运行，没有系统推送、邮件或短信提醒。
- 本机数据没有加密或独立密码保护。共用电脑或浏览器配置的人可能访问这些数据，请避免输入密码、证件信息等敏感内容。

## 分享版与个人自用版的区分

这是独立的本地分享副本，保留原程序的业务逻辑和布局，仅做以下发布处理：

1. 页面标题及品牌位置标明“本地分享版”。
2. 预置课程替换为“示例课程 A / 示例课程 B”，课程编号改为通用编号，默认任务列表为空。
3. 使用独立的浏览器存储键，不读取、迁移、覆盖或清除其他版本的存储键：

   ```text
   studybloom_public_local_courses_v1
   studybloom_public_local_tasks_v1
   studybloom_public_local_settings_v1
   ```

独立存储键用于防止版本误用，并不是安全隔离或加密措施。不要将其他版本改用这些键，也不要在同一存储位置保存多份使用这些键的分享版并期待数据相互隔离。

## 隐私与网络行为

- 本仓库只发布程序和说明，不包含作者的浏览器存储、任务备份、截图、账号信息、密钥或托管部署文件。
- 当前源码没有 `fetch`、XMLHttpRequest、WebSocket 或埋点上传调用，没有外部脚本和字体依赖，不主动上传课程、任务或设置。
- SVG 图标中的 XML 命名空间地址用于描述 SVG，不是联网同步接口。
- 若后续自行部署到静态托管服务，服务商仍可能记录页面访问请求；这不代表任务会被同步。不要将个人数据直接硬编码进 HTML、README、截图或提交记录后公开。
- 提交 issue 时，请使用虚构课程和任务复现问题，并遮挡私人信息。
