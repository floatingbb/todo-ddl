# ToDo deadline list · 本地分享版

一个使用柔和配色的课程待办工作台。页面、样式和脚本全部包含在 `ToDo.html` 中，下载后直接用浏览器打开，无需安装依赖、构建项目、注册账号或配置服务器。

> **这是本机保存的单文件程序，不支持账号登录或多设备自动同步。** 电脑、手机、不同浏览器之间的数据各自独立；相同 GitHub 账号、浏览器账号或同一个 HTML 文件，都不会让本程序自动同步任务。跨设备迁移需手动导出、导入 JSON。

## 快速开始

1. 在仓库页面选择 **Code → Download ZIP**，下载并解压。
2. 使用现代浏览器打开解压后的 `ToDo.html`。GitHub 源码浏览页面不会直接运行这个程序。
3. 在“管理课程”中修改两个示例课程，或添加自己的课程。
4. 点击“添加任务”，设置名称、所属课程、重要性、截止日期时间和说明。
5. 在“工作台设置”中修改标题、说明和主题颜色。

首次打开只有“示例课程 A / 示例课程 B”，没有预置任务。下载后的文件可以离线使用，无外部脚本、字体服务、登录服务或数据接口依赖。浏览器需允许 JavaScript、`localStorage`，并支持页面使用的现代 CSS。

## 最新更新

- **已完成任务折叠**：电脑、手机都将完成任务集中到“已完成 N 项”，默认收起，点击展开后仍可编辑、删除或改回未完成。
- **展开状态保留**：当前视图每分钟刷新时间提示时不会突然收起；切换到“已完成”筛选默认展开，也可以手动收起。
- **手机双行筛选**：课程标签位于状态标签正上方，两行左右对齐，课程较多时可横向滑动；电脑课程分类继续放在侧栏。
- **紧凑手机界面**：四个紧凑统计卡、可折叠课程进度、固定在右下角的添加任务按钮和底部弹窗。
- **本地 JSON 备份**：电脑顶部、手机“⋯”菜单提供导出/导入入口，支持手动迁移数据。
- **交互修复**：全部任务按钮不再重复绑定事件；主题预览取消、点叉、点遮罩或按 Esc 都会恢复原色，点保存才持久保存。

## 使用备份和跨设备迁移

### 导出

电脑点击顶部“导出备份”；手机点“⋯”再点“导出备份”。保存下载的 `StudyBloom-local-日期.json`。导出不删除原记录。

### 导入

在目标设备打开程序，电脑顶部或手机“⋯”菜单点“导入备份”，选择 JSON 并确认。

- 导入是**合并**，不是整库替换；相同 `id` 的记录以导入文件为准。
- 未出现在备份中的现有记录不会自动删除。
- 名称相同但编号不同的记录不会自动去重。
- 工作台名称和主题设置也会随备份导入。
- 选择本程序或兼容版本导出的 JSON，文件需在 5 MB 以内；格式、编号或颜色字段不合法时会拒绝导入。
- JSON 含个人任务和说明，请自行妥善保存，勿上传到公开仓库。

手动导出/导入只是迁移或备份，**不是实时同步**。两台设备继续各自编辑后，记录不会自动合并。

## 更新程序时保留已有数据

本次更新保留分享版原有的三个存储键，不自动读取、迁移、覆盖或清空其他版本的键：

```text
studybloom_public_local_courses_v1
studybloom_public_local_tasks_v1
studybloom_public_local_settings_v1
```

更新前先导出一份 JSON。用新代码覆盖原文件时，尽量保留原路径、原文件名、同一浏览器及同一浏览器用户配置。直接打开下载目录中的另一份文件可能读不到原记录；可通过导入 JSON 恢复到该副本。

独立键用于防止版本误用，并非安全隔离或加密。多份使用相同键的页面，如果处在同一个浏览器存储范围内，仍可能共用或互相覆盖数据。

## 数据保存的限制

- **没有账号、服务器、云数据库或自动多设备同步。** GitHub 只分享代码，不保存你填入的任务。
- 复制 HTML 只会复制程序，不会复制浏览器里的记录。备份 HTML 不能代替备份 JSON。
- 不同设备、浏览器、用户配置的数据通常各自独立。
- 通过 `file://` 打开时，存储行为取决于浏览器；移动、改名或更换打开方式后可能无法访问原数据。
- 清理浏览器站点数据、删除用户配置、隐私模式退出或存储受限，都可能导致数据丢失或保存失败。
- 没有跨标签页合并机制；同一存储位置同时打开多个页面编辑可能互相覆盖，建议只在一个页面编辑。
- 关闭页面后不会在后台运行，没有系统推送、邮件、短信或日历提醒。
- 截止时间按设备本地时区解释，日期展示不包含年份；跨时区使用需核对时间。
- 本机数据没有加密或独立密码保护。共用浏览器配置的人可能访问记录。
- 手机能否直接打开本地 HTML 取决于系统、浏览器和打开方式；文件预览器未必执行脚本或允许持久存储。

## 隐私与网络

- 公开文件只含程序、通用示例课程和说明，不包含作者的任务、完成记录、截图、浏览器缓存、个人备份或账号配置。
- 源码没有数据上传、网络同步、埋点或外部脚本/字体依赖。
- SVG 图标中的命名空间地址用来描述 SVG，不是同步接口。
- 后续自行部署到静态托管服务时，服务商可能记录访问请求；这不代表任务会同步。
- 请勿将个人数据硬编码到程序、截图、issue 或提交历史里。
